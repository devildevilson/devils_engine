# GN09 на инструментах libs/originator

План полного перевода (2026-10-31). Отметки ведутся по ходу работы.

## Конечное состояние

В `world.tavl` все генераторы — lua; нативных тел и объектов хоста нет: мир и постройки лежат в
буферах, моды заменяют любое правило. На C++ в GN09 остаются только:

1. блоки-инструменты с обещаниями хоста (порода вокруг, «уместилось ли», скрытость, точная геометрия
   вокселей и сеток);
2. формулы словаря форм — до колоночного `ds` и видов форм на `ds`;
3. независимая проверка `--verify` (второй путь, не копия генератора);
4. просмотрщик, отчёты, SVG.

## Решения

- Общий код скриптов — общие модули цепочки (`modules = [ ... ]`, `modules.<имя>` в теле шага).
- Поверхность — marching tetrahedra GN09 становится инструментом библиотеки (геометрия побитово та же;
  на этом разбиении держится доказательство защитного слоя).
- Перенос ТОЧНЫЙ: порядок вытягиваний случайности как в C++, мир тот же. Отступ — только вслух, с
  перемером 16 зёрен.
- `verify` остаётся C++ и читает буферы.

## Ворота каждого шага

Отпечатки `--bench` (зёрна 0, 5, 17), отчёт `--verify` на 4 зёрнах побайтно, сверка чанков цепочки с
окном 7x7.

## Этапы

- [x] 0. Библиотека: общие модули цепочки; `field_sample` с меткой вида.
- [x] 1. Залы: `halls` в lua (рельеф слоя и общие помощники — модуль `world`), блоки
      `hall_niche_fits` (вход ниши в воде, дно скрыто от петли) и `hall_relevance` (область влияния);
      `creature_home` / `creature_places` / `creature` в lua, «тело проходит» — `field_sample` по полю
      `passage`. Ниши проверяются аналитически по формам зала, отдельный генератор ниш не понадобился.
      Проверено: дамп всех полей залов (5 зёрен, регионы -3..3) побитово, отчёт --verify 4 зёрен,
      отпечатки --bench; существа — сверкой с C++-эталоном на всех залах регионов -3..3.
- [x] 2. Станции: генератор `station` (lua: якорь, место лучами `field_march` с уточнением и плоскостью,
      запретная геометрия, рост графа помещений, двери); блоки `station_room_cells` (ленивая маска в
      буферах) и `station_build` (воксели, сетка, коробка); аванпосты залов — данные генератора `halls`;
      `station_for` — представление экземпляра (`generator_result::view`), кэш — кэш цепочки.
      Проверено: дамп всех станций окна (4 зерна, 150 якорей) побитово, отчёт --verify 4 зёрен.
      Цена: --verify 4 зёрен 168 -> 215 с; lua ~5%, рост — вычисления поля (пещеры мест окна,
      которые C++ не трогал). Кандидат: ленивый fan-in в полях.
- [x] 3. Туннели: `tunnel_candidates` (якоря в досягаемости), `tunnel_partner` (ближайший с построенной
      станцией), `tunnel_link` (взаимность, первый якорь, окрестность середины), `tunnel_scope` (станции у
      середины), `tunnel` (lua: выходы из внутренних помещений, варианты трассы, куски, порода по полям
      `natural_sites` и `carves`); блок `tunnel_build` (сетка, коробка); правило якорей окна — в модуле
      `world`. Найдено: повторный захват замка экземпляра (разбор строк вида -> представление) —
      разбор и представления собираются без замка.
- [x] 4. Окно без объекта хоста: `window` — lua (форма галереи, карман, радиус и порода шара поворота;
      обещания хоста — значения из C++-констант), C++-мир — `world_view` (граф и залы из буферов).
      C++ `shape_edge` остался только у проверки и пути prepare_field — сверка чанков цепочки с окном
      7x7 сверяет lua-галереи с C++ (0 расхождений на 243 чанках). Комнаты баз — генератор `base_site`,
      залежи мест — шаг `S03_features` пещеры. Проверено дампом мест 4 зёрен побитово.
- [x] 5. Чанк на цепочке целиком: нативный `chunk_structures` удалён; `chunk_anchors` (якоря в
      досягаемости, правило из модуля `world`) и `chunk_tunnels` (взаимные туннели без повторов) дают
      fan-in станций и туннелей полю `solid`. `chunk_field`: решётка 19^3 с полосой, поверхность
      инструментом библиотеки `marching_tetrahedra`, вид породы клетки — метка `field_sample` у середины
      её поверхности, обрезка сеток построек — блок `structure_surface`, предметы пещер мест — буфер
      `props`. Просмотрщик берёт из экземпляра всё. Проверено: 0 вершин расходятся с хостовой сеткой на
      зёрнах 0/5/17, отпечатки чанков цепочки прежние, предметы равны прежнему списку просмотрщика.
- [x] 6. Проверка на буферах: всё, что проверяет `--verify`, приходит из выходов экземпляров через
      представления (`world_view`, `site_view`, `station_view`, `tunnel_view`) — чистые функции буферов;
      порчи делаются на копиях представлений. Последний объект хоста — исполнитель `cave` — удалён:
      блоки `cave_fits`/`cave_hidden` находят окно, узел и старших соседей через цепочку по ключу пещеры
      (`layout_meta`), точки лодки — чистая мемоизация, `site` — представление. В цепочке больше нет
      нативных тел, исполнителей и полезных нагрузок.
- [x] 7. Библиотека: `graph_slope` и `graph_vote` — на общих ядрах соседства (`slope_range`,
      `vote_range`; новые инструменты `slope`, `vote`), пакеты GN02 побайтно те же. `collapse` не
      переводится: его правила направленные (матрица на ось), а соседство вызова оси дуги не называет.
- [ ] Потом: колоночный `ds` (стенды — маска станции и поле чанка), виды форм на `ds`.
